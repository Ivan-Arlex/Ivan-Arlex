# 👋 ¡Hola! Soy Iván Arlex Buenaventura Riascos

Estudiante de **Ingeniería de Sistemas** en la **Universidad del Pacífico**, enfocado en el **desarrollo backend, diseño de arquitectura de software y desarrollo de APIs**.

Trabajo activamente con **Java y Spring Boot** como mi entorno principal backend, e integro **Python, FastAPI, LangChain y LangGraph** para construir aplicaciones impulsadas por **agentes de Inteligencia Artificial, sistemas RAG y flujos de trabajo automatizados**.

> 💡 Me interesa construir software que no solo funcione, sino que mantenga una arquitectura limpia, sea mantenible y evolucione de forma orgánica con las necesidades del proyecto.

- 🎓 Estudiante de **Ingeniería de Sistemas**.
